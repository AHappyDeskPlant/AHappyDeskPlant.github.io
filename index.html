Research

A Practical Block-Sampling Particle Filter

Warwick MSc dissertation, 2026. Supervised by Prof. Adam Johansen.

Particle filters track a hidden state through noisy data, but each resampling step thins out their memory of the past. Block sampling fixes this by revising earlier states with later observations, yet it only has a closed form for linear Gaussian models. I trained a conditional VAE to learn it offline, so each online step takes a single forward pass.

On simulated data and real USD/GBP returns, it reduced the variance of the likelihood estimates and beat an independently trained network, though the gains were modest on harder models. A useful lesson: the VAE’s training loss doesn’t control the filter’s weight variance, so I checked proposals with filter diagnostics instead.
